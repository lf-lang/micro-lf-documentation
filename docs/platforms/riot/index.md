# RIOT

- **Template**: [ulf-riot-template](https://github.com/lf-lang/ulf-riot-template)
- **RIOT Documentation**: [doc.riot-os.org](https://doc.riot-os.org/)
- **Supported Boards**: [RIOT Board Support](https://www.riot-os.org/boards.html)

## Prerequisites

In addition to the [common prerequisites](../index.md#common-prerequisites):

- **make** version 4.0+ (on macOS, install via `brew install make` and use `gmake`)
- **ARM cross-compiler** for ARM-based boards:

```bash
# Debian/Ubuntu
sudo apt install gcc-arm-none-eabi

# Or use Nix
nix develop
```

## Setup

Clone and initialize submodules:

```bash
git clone https://github.com/lf-lang/ulf-riot-template.git my-project
cd my-project
git submodule update --init --recursive
```

## Building

Set `BOARD` in the `Makefile` (default: `native`), then:

```bash
make all
```

Or override it on the command line:

```bash
make BOARD=nucleo-f446re all
```

`BOARD=native` builds an executable that runs on your development machine,
**on Linux only**. See [RIOT Board Support](https://www.riot-os.org/boards.html)
for board names.

## Flashing

```bash
make flash
```

Or with parameters:

```bash
make LF_MAIN=HelloWorld BOARD=nucleo-f446re flash
```

## Terminal

Open a terminal connected to your program's stdin/stdout:

```bash
make term
```

## Changing the Application

Set `LF_MAIN` in the `Makefile` (default: `HelloWorld`) or on the command line:

```bash
make LF_MAIN=MyApp BOARD=nucleo-f446re all
```

## Log Level

Edit the `Makefile` (default: `LF_LOG_LEVEL_ERROR`):

```makefile
CFLAGS += -DLF_LOG_LEVEL_ALL=LF_LOG_LEVEL_DEBUG
```

## Cleaning

`make clean` removes the RIOT build output and the code generated by `ulfc`
for the current `LF_MAIN`:

```bash
make clean
```

## Network Channels

| Channel | Mode | Description |
|---------|------|-------------|
| TCP/IP | Async | TCP sockets via RIOT's GNRC stack |
| CoAP/UDP | Async | CoAP over UDP for IoT networks |
| UART | Polled, Async | Serial point-to-point |

## macOS Notes

Use `gmake` instead of `make` (macOS ships with make 3.81, RIOT requires 4.0+):

```bash
brew install make
gmake all
```
