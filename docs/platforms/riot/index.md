# RIOT

- **Template**: [ulf-riot-template](https://github.com/lf-lang/ulf-riot-template)
- **RIOT Documentation**: [doc.riot-os.org](https://doc.riot-os.org/)
- **Supported Boards**: [RIOT Board Support](https://www.riot-os.org/boards.html)

The RIOT template builds micro-LF applications with RIOT's `make`-based build system, for any board supported by RIOT.

## Prerequisites

In addition to the [common prerequisites](../index.md#common-prerequisites):

- **make 4.0+** (macOS ships an older version, see [Notes](#notes))
- **ARM cross-compiler** for ARM-based boards, e.g. on Debian/Ubuntu:

```bash
sudo apt install gcc-arm-none-eabi
```

If you use [Nix](https://nixos.org), run `nix develop` in the project directory to get these tools instead.

## Setup

Clone the template and initialize the RIOT submodule:

```bash
git clone https://github.com/lf-lang/ulf-riot-template.git my-project
cd my-project
git submodule update --init --recursive
```

## Building

Set `BOARD` in the `Makefile` (default: `native`), or on the command line:

```bash
make BOARD=nucleo-f446re all
```

`BOARD=native` builds an executable that runs on your computer, **on Linux only**. See [RIOT Board Support](https://www.riot-os.org/boards.html) for board names.

## Flashing

```bash
make BOARD=nucleo-f446re flash
```

To see the program's output, open a terminal connected to its stdin/stdout:

```bash
make BOARD=nucleo-f446re term
```

On Windows, first attach the board to WSL: see [Windows (WSL)](../../getting-started/wsl.md).

## Changing the Application

Set `LF_MAIN` in the `Makefile` (default: `HelloWorld`), or on the command line:

```bash
make LF_MAIN=MyApp BOARD=nucleo-f446re all
```

## Log Level

Edit this line in the `Makefile` (default: `LF_LOG_LEVEL_ERROR`):

```makefile
CFLAGS += -DLF_LOG_LEVEL_ALL=LF_LOG_LEVEL_DEBUG
```

## Cleaning

Remove the RIOT build output and the files generated by the micro-LF compiler for the current `LF_MAIN`:

```bash
make clean
```

## Network Channels

| Channel | Description |
|---------|-------------|
| TCP/IP | TCP sockets via RIOT's GNRC network stack |
| CoAP | CoAP over UDP, e.g. on IEEE 802.15.4 networks |
| UART | Serial point-to-point link, polled or interrupt-driven (`async=true`) |

For a federated program, build and flash each federate separately with `LF_FED`:

```bash
make LF_MAIN=MyFederatedApp LF_FED=r1 BOARD=nucleo-f446re all flash
```

## Notes

- **macOS**: install a recent make with `brew install make` and use `gmake` instead of `make` in all commands.
