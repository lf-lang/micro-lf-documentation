## Prerequisites

In addition to the [common prerequisites](../index.md#common-prerequisites):

1. Install the Zephyr dependencies: [Install Dependencies](https://docs.zephyrproject.org/4.1.0/develop/getting_started/index.html#install-dependencies)
2. Install the Zephyr SDK and toolchains: [Install the Zephyr SDK](https://docs.zephyrproject.org/4.1.0/develop/getting_started/index.html#install-the-zephyr-sdk)

## Setup

Clone the template and create a Python virtual environment inside it:

```bash
git clone https://github.com/lf-lang/ulf-zephyr-template.git my-project
cd my-project
python3 -m venv ./venv
source ./venv/bin/activate
```

Install west and fetch the Zephyr sources (this can take a while):

```bash
pip install west
west update
pip install -r deps/zephyr/scripts/requirements.txt
west zephyr-export
```

!!! note
    Activate the virtual environment (`source ./venv/bin/activate`) in every new
    terminal before using `west`. Errors such as `Command 'west' not found` or
    `No module named 'elftools'` indicate that the virtual environment is not active.

## Building

Build and run `HelloWorld` using the `native_posix` target (emulation):

```bash
west build -t run
```

Build for a specific board:

```bash
west build -b qemu_cortex_m3 -p always -t run
west build -b adafruit_feather -p always
```

The `-p always` flag cleans the build directory, which is required when changing
the target board.

## Flashing

```bash
west flash
```

This may require additional vendor-specific tools.
For more information, see the [Zephyr Flashing Guide](https://docs.zephyrproject.org/4.1.0/develop/getting_started/index.html#flash-the-board).

## Changing the Application

Set the `LF_MAIN` CMake variable in `CMakeLists.txt` or via command line
(CMake arguments follow `--`):

```bash
west build -b adafruit_feather -p always -- -DLF_MAIN=Blinky
```

## Log Level

```bash
west build -t run -p always -- -DLOG_LEVEL=LF_LOG_LEVEL_DEBUG
```

## Cleaning

`-p always` only cleans the CMake build. To also remove the files generated by
`ulfc`, use the template's custom west command:

```bash
west clean
```

## Network Channels

| Channel | Description |
|---------|-------------|
| TCP/IP | TCP sockets over Ethernet/WiFi |
| BLE | Bluetooth Low Energy via the Zephyr Bluetooth stack (`@interface_ble`) |
| UART | Serial point-to-point |
