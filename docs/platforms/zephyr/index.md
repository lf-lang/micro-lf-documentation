# Zephyr

- **Template**: [ulf-zephyr-template](https://github.com/lf-lang/ulf-zephyr-template)
- **Zephyr Documentation**: [docs.zephyrproject.org](https://docs.zephyrproject.org/4.1.0/)
- **Supported Boards**: [Zephyr Board Index](https://docs.zephyrproject.org/4.1.0/boards/index.html)

The Zephyr template builds micro-LF applications with `west`, the Zephyr build tool, for any board supported by Zephyr, including emulated boards that run on your computer.

## Prerequisites

In addition to the [common prerequisites](../index.md#common-prerequisites):

1. Install the Zephyr dependencies: [Install Dependencies](https://docs.zephyrproject.org/4.1.0/develop/getting_started/index.html#install-dependencies)
2. Install the Zephyr SDK and toolchains: [Install the Zephyr SDK](https://docs.zephyrproject.org/4.1.0/develop/getting_started/index.html#install-the-zephyr-sdk)

## Setup

Clone the template and create a Python virtual environment inside it:

```bash
git clone https://github.com/lf-lang/ulf-zephyr-template.git my-project
cd my-project
python3 -m venv ./venv
source ./venv/bin/activate
```

Install west and fetch the Zephyr sources (this can take a while):

```bash
pip install west
west update
pip install -r deps/zephyr/scripts/requirements.txt
west zephyr-export
```

!!! note
    Activate the virtual environment (`source ./venv/bin/activate`) in every new
    terminal before using `west`. Errors such as `Command 'west' not found` or
    `No module named 'elftools'` mean that it is not active.

## Building

Build and run the default application, `HelloWorld`, on the emulated `native_posix` board:

```bash
west build -t run
```

Build for a specific board:

```bash
west build -b qemu_cortex_m3 -p always -t run
west build -b adafruit_feather -p always
```

The `-p always` flag cleans the build directory, which is required when changing the target board.

## Flashing

```bash
west flash
```

This may require additional vendor-specific tools; see the [Zephyr Flashing Guide](https://docs.zephyrproject.org/4.1.0/develop/getting_started/index.html#flash-the-board). On Windows, first attach the board to WSL: see [Windows (WSL)](../../getting-started/wsl.md).

## Changing the Application

Set the `LF_MAIN` variable in `CMakeLists.txt`, or on the command line (CMake arguments follow `--`):

```bash
west build -b adafruit_feather -p always -- -DLF_MAIN=Blinky
```

## Log Level

```bash
west build -t run -p always -- -DLOG_LEVEL=LF_LOG_LEVEL_DEBUG
```

## Cleaning

`-p always` only cleans the CMake build. To also remove the files generated by the micro-LF compiler, use the template's custom west command:

```bash
west clean
```

## Network Channels

| Channel | Description |
|---------|-------------|
| TCP/IP | TCP sockets over Ethernet or Wi-Fi |
| UART | Serial point-to-point link |
| BLE | Bluetooth Low Energy link between two boards (`@interface_ble`) |
